## ブラウザーでの確認

結合テストが出力した日本語HTMLを、MT本体のCSS・JavaScriptとともにローカルで表示した。

- 両テーマで、既存の4つの検索オプションの末尾に「Jev」が並ぶ。
- 説明文は次の行に表示され、Jevを外すと非表示になる。
- Jevを外すと大文字／小文字・正規表現を再び選択できる。
- `admin2025` のシステム設定で、保存済みキーのマスク表示と「APIキーを更新」による空の入力欄の展開を確認した。
- `admin2025` の実際のSvelteヘッダー検索を開き、入力欄の直下に初期ONの「Jev を使う」が表示されることを確認した。
- ヘッダーでONにしてボタン送信すると `is_jev=1`、OFFにしてEnter送信すると `is_jev` なしで送信されることを、ローカルのリクエスト受信ページで確認した。
- 幅390pxのモバイルメニューでも、入力欄直下の表示とEnterによる `is_jev=1` の送信を確認した。
- 設定画面に「ヘッダー検索で Jev を標準で使用」がON/OFF選択欄として表示されることを確認した。設定保存は一時DBを使う結合テストで検証した。

ヘッダーのブラウザー検証では、コンテンツタイプ一覧の取得と検索送信先をローカルの検証用レスポンスに差し替えた。本体のフロントエンドコードとプラグインのコードを使用しているが、実APIへは接続していない。

## 配布パッケージのビルド

AI-Assistant の `Makefile.PL`、`compose.yml`、`Dockerfile`、`MANIFEST.SKIP` を参考にビルド構成を追加した。Docker Compose の `builder` を実行し、次を確認した。

- `config.yaml` のバージョンから `Jev-0.1.0.tar.gz` と `Jev-0.1.0.zip` を生成できる。
- 両アーカイブの15ファイルがソースとバイト単位で一致する。README、設定、Perlモジュール、テンプレート、JavaScript、CSSが含まれる。
- テスト、仕様書、ビルド用ファイル、Git情報、以前のアーカイブが配布物に含まれない。
- 同じバージョンで再ビルドでき、ZIPへ仮に追加した古いファイルが再ビルド後には残らない。
- 一時コンテナ内で `--version 0.1.0-dev` を指定した配布物を生成できる。
- 一時コンテナ内で不正なJavaScriptを加えると `make build` が失敗し、構文エラーを検出できる。
- 生成されたアーカイブ、Makefile、MANIFEST、MYMETAは `.gitignore` の対象になる。

実行手順はREADMEの「ビルド」に記載した。`make dist` と `make zipdist` は、AI-Assistant と同じく別々に実行する。
