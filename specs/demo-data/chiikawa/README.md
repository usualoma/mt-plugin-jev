# 「アニメの感想」用のちいかわダミー記事100件

[chiikawa-reviews-100.txt](chiikawa-reviews-100.txt) がMTインポート用のファイル。UTF-8・LF、100記事、約177 KB。本文はすべて `BODY` のHTML段落に入っている。記事は386〜547文字、平均約469文字（HTMLタグを除く）。

**映画・放送回のあらすじ、結末、感想はすべて検索デモ用の創作。実在作品の内容や公開・放送実績を表すものではない。** 各本文末尾にも架空の内容であることを記した。「ちいかわ」の表記は残し、架空の映画名や各話タイトルは付けていない。記事タイトルは「ちいかわの映画 — 小さな仕草を何度も思い出す」のように、媒体と感想の見出しで構成する。

映画とテレビアニメの感想を50件ずつ作った。25種類の架空の筋書きに対し、媒体・結末への言及・評価を変えた感想を用意し、ラベル順にならないよう混ぜてある。

## 内訳

| 媒体 | ネタバレ | 肯定的 | 否定的 | 小計 |
| --- | --- | ---: | ---: | ---: |
| 映画 | なし | 13 | 12 | 25 |
| 映画 | あり | 12 | 13 | 25 |
| テレビアニメ | なし | 12 | 13 | 25 |
| テレビアニメ | あり | 13 | 12 | 25 |
| **合計** | | **50** | **50** | **100** |

映画／テレビアニメ、ネタバレあり／なし、肯定的／否定的はそれぞれ50件ずつ。任意の2条件の組み合わせは25件ずつ、3条件の組み合わせは12件または13件になる。

「ネタバレあり」の50件は本文冒頭に **「ネタバレ注意」** を入れ、物語の結末・種明かし・問題の解決を具体的に記述する。「なし」の50件にはこのキーワードを入れず、導入と演出の感想だけに留める。架空の筋書きなので、ここでの分類は実在作品のネタバレ判定ではない。

肯定的な感想にも軽い不満を、否定的な感想にも絵や人物への好意を含めている。判定対象は筆者の**作品全体への評価**。「かわいい」という単語だけでは肯定・否定を分けられない。具体的な結末が本文の後半にだけ登場する記事も18件含むが、注意書きはいずれも本文冒頭に置く。

## ファイル

| ファイル | 用途 |
| --- | --- |
| [chiikawa-reviews-100.txt](chiikawa-reviews-100.txt) | MTに取り込む100記事 |
| [manifest.csv](manifest.csv) | 記事ごとの媒体・ネタバレ・評価などの正解ラベル。UTF-8 BOM付き |
| [queries.json](queries.json) | 3条件を組み合わせた検索例8件と想定該当ID |
| [generate_dataset.py](generate_dataset.py) | 同じファイルを再生成するPythonスクリプト。標準ライブラリのみ |

`CKW-0001` などの識別子はタイトルとCSVの照合用で、MTのDB上の記事IDとは別。正解ラベルをインポート用のタグやキーワード欄に入れてはいない。カテゴリーは「映画」「テレビアニメ」の2種類。

CSVの `scenario_id` は筋書きを区別するための内部ID（`S01`〜`S25`）。映画名や各話タイトルではない。

## 取り込み

1. MTで取り込み先のサイト「アニメの感想」を選択する。MT形式のファイル自体はサイトを作成しない。
2. 記事インポートでMovable Type形式とUTF-8を選び、`chiikawa-reviews-100.txt` を指定する。
3. 記事の所有者として既存ユーザーを指定する。ファイルに `AUTHOR` は含めていない。

100件すべて `STATUS: Draft`（下書き）。`EXTENDED BODY`、`EXCERPT`、`KEYWORDS` は空で、コメント・トラックバックは無効。再インポートすると記事が追加される。

JevのOpenAIキーを設定済みなら、インポート時の保存でもembedding生成が走る。キーを後から設定した場合は、MTルートで次を実行して索引を作る。

```sh
perl tools/Jev/build-index --blog-id 対象サイトのID --type entry
```

## 検索例

- ちいかわの映画の感想で、結末に触れずに全体として楽しめたと書いている記事
- ちいかわのテレビアニメの感想で、具体的な結末を明かしていて、作品全体には不満がある記事
- ちいかわの映画の感想で、かわいさは認めているが、全体としては評価が厳しい記事

CSVと検索例の件数は**全100件を対象とする作成時の想定値**であり、APIによる実測値ではない。現在の検索は既定でembedding上位50件を判定するため、全件の想定値と比較する場合は対象サイトを絞り、候補数を100以上にする。

## 再生成

```sh
python3 specs/demo-data/chiikawa/generate_dataset.py
```

生成スクリプトは100件、本文の重複なし、各条件50件、2条件の全組み合わせ各25件、3条件の全組み合わせ各12〜13件を確認する。

MT9の標準 `MT::ImportExport` と一時SQLite DBで100件の取り込みを確認した。タイトル・BODYは全件で完全一致し、2カテゴリー、全件下書き、他の本文欄が空であることも確認済み。確認時はJevプラグインを無効にし、外部APIは呼んでいない。
